## 🚀 Funcionalidades Principais
- **Auto-Reset no Dashboard:** O painel do motorista retorna automaticamente ao estado de espera ('Standby') quando a ocorrência é resolvida pela central, melhorando o fluxo operacional.
- **Polling de Segurança:** Implementação de fallback (3s) para garantir sincronização de status mesmo se o WebSocket (Realtime) falhar.
- **Design de Botões:**
    - Botão "Assumir" (Admin) agora em Vermelho/Pulsante.
    - Botão "Meu Cadastro" (Driver) padronizado em Azul.
